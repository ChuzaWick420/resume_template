# Resume Template (ATS Friendly)
This resume template is inspired by (basic resume typst)[^1]. In the original inspiration, the lengthy links (especially `LinkedIn` one) were breaking into multiple lines which has potential to confuse ATS systems. My implementation creates $n \times 2$ columns for the contacts instead of line breaking them. Rest of the implementation is visually similar.

## Pre-requisites

- Install `typst 0.14.2+`.

## How to use

```
typst compile main.typ John_Resume.pdf
```
